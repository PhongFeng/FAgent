# FAgent

基于开源工具与 Godot 标准版（非 .NET）的游戏制作工作流。通过实际制作游戏，逐步沉淀可复用的 Agent、Skill 和项目模板，让其他用户能更快地从想法走到可玩的游戏。

当前阶段：**规划通用工具体系，首款游戏类型待定**。Agent 在这里指协助开发的角色，不是游戏内 NPC。

## 基本方向

- 引擎采用 Godot 标准版，主要脚本语言为 GDScript。
- 先跑通一个小型游戏的制作闭环，再根据真实任务提炼能力；首版以单机、单平台交付为建议范围。
- Agent 负责目标、分工和交付；Skill 提供可重复执行的方法、脚本与验证步骤。
- 核心工作流采用可阅读的文件和命令行接口，支持人工执行与不同 Agent 宿主适配。
- 开源软件、模型权重和素材分别记录许可证，逐项确认可分发范围。

## Game AI开发流程

以下流程用于开发本仓库的 [f-game 游戏](godot/f-game/project.godot)，覆盖从立项到上线后持续更新的完整生命周期。随着游戏开发推进，将实际使用的方法、工具和验证步骤沉淀为可复用的 Agent 与 Skill；各阶段按游戏实际进度展开。

### 前期

- 立项与策划：需求文档、世界观、玩法系统

### 中期

- 美术生产：概念图、2D/3D资源、动画
- 程序开发：代码生成、调试、工具编写
- 音频制作：音乐、音效、语音生成
- 数值设计：数值建模与模拟

### 后期

- 质量保证：自动化测试、智能探索、性能测试
- 宣发准备：美宣素材、视频、多语言文案

### 上线

- 运营与增长：数据分析、玩家分群、预测模型
- 社区与客服：智能客服、社区分析、内容管理

### 持续

- 内容更新：关卡/内容生成、成长曲线规划

## 仓库现状

`godot/f-game/` 是现有 Godot 项目骨架。配置声明了 `4.7` 特性和 Mobile 渲染模式，尚未配置主场景。该声明不代表本机引擎版本已经验证，也不作为通用模板的版本选择。

当前提交内容以方案文档为主。Agent 定义、可安装 Skill、自动化脚本和可玩示例尚待实现；目录与协议示意均在设计文档中标明。现有游戏骨架保持原样。

首个实现目标是：用户提交游戏简报后，工作流可以检查环境、建立可运行项目、完成一个核心玩法任务，并提供可追溯的验证结果。

## Game AI
AI Game Development：Multi-Agent System  
多 Skill 协作工作流  

## Game AI开发流程
### 前期
* 立项与策划：	需求文档、世界观、玩法系统  
### 中期
* 美术生产：	概念图、2D/3D资源、动画  
* 程序开发：	代码生成、调试、工具编写  
* 音频制作：	音乐、音效、语音生成  
* 数值设计：	数值建模与模拟  
### 后期
* 质量保证：	自动化测试、智能探索、性能测试   
* 宣发准备：	美宣素材、视频、多语言文案   
### 上线  
* 运营与增长：	数据分析、玩家分群、预测模型   
* 社区与客服：	智能客服、社区分析、内容管理   
### 持续
* 内容更新：	关卡/内容生成、成长曲线规划
